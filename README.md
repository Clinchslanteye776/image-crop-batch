## 🖼️ Crop Modes Explained

image-crop-batch gives you two clear ways to crop a folder. Both are designed around folders, so you can process many images in one pass.

### ⬛ Same Box for Every Image

The same-box mode applies one crop rectangle to every image in the selected folder. This is helpful when all your images have a similar layout and you want the final crops to line up. For example, if you have a folder of screenshots and you always want to remove the same outer edges, same-box cropping lets you define that box once and apply it across the folder.

This mode is also useful for product photos taken from the same distance, scanned pages with consistent margins, or image sets where the subject appears in roughly the same place. You set the box, run the batch, and the app creates cropped versions for the folder.

### ⬜ Center Square Crop

Center square mode turns each image into a square by cropping around the middle. This is the quickest way to prepare images for places that expect square pictures, such as profile images, app tiles, thumbnails, and simple preview cards. The app finds the center of each image and keeps a square area there.

Center square cropping is useful when your folder contains images of different sizes but you want a consistent square result. It removes the guesswork of making each image square by hand. The main subject stays in the middle, and the extra edges are trimmed away.

## 📁 Folder Tips for Better Results

Keep your original images in their own folder and let image-crop-batch create cropped copies in a separate output folder. That way your source files stay untouched, and you can compare the originals with the cropped results.

Use clear folder names such as product-photos-original, product-photos-cropped, profile-pictures-source, or profile-pictures-square. Clear names make it easier to find the right folder when you are selecting images inside the app.

If you are cropping a large folder, try a small test folder first. Put a few representative images into a test folder, run the crop, and check the results. Once the crop box or center square setting looks right, run the same setting on the full folder.

Avoid mixing very different image types in one same-box batch unless you have checked the results. For example, wide screenshots and tall portrait photos may need different crop settings. Center square mode is more forgiving when image sizes vary, because it focuses on the middle of each image.
